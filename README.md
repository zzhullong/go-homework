## 仓库结构

本仓库汇总了以下三个作业项目，每个项目以独立文件夹存放：

| 文件夹 | 原仓库 | 说明 |
| --- | --- | --- |
| `homework-blog/` | [zzhullong/homework-blog](https://github.com/zzhullong/homework-blog) | Go + Gin 博客后端（用户、文章、评论、JWT 鉴权） |
| `go-homework-01/` | [zzhullong/go-homework-01](https://github.com/zzhullong/go-homework-01) | Go 作业一 |
| `go-homework-03/` | [zzhullong/go-homework-03](https://github.com/zzhullong/go-homework-03) | Go 作业三（博客 DAO/Service 分层与测试） |

> 各子文件夹内的 `go.mod` 互相独立，进入对应目录后单独执行 `go build` / `go test`。
> 原仓库仍保留在 GitHub 上，本仓库只是内容快照。
